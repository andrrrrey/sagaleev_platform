# CLAUDE.md — Платформа «Цифровой отдел маркетинга» (Фаза 1)

Закрытый портал для собственников микробизнеса: обучающий курс + рабочая среда, где студент собирает своего маркетингового ИИ-агента. Исполнитель: futuguru. Заказчик: Жаргал.

**Ключевой принцип продукта:** прогресс = что студент реально внедрил в бизнесе, а не сколько видео посмотрел.

## Как работать с этим репозиторием

Перед любой задачей читай нужные файлы из `docs/`:

## Жёсткие правила

1. **Дизайн 1:1 с `docs/reference/docuframe-hero.html`.** Токены, шрифты, рамки, уголки, штриховка, «линованная бумага», моно-лейблы, иконки Solar Linear. Цвета из КП (тёмная тема + gold) **игнорируются**. Не добавляй скругления, тени, градиенты и цвета, которых нет в эталоне. Если нужного паттерна в эталоне нет, собери его из существующих токенов (см. `02-design-system.md`, раздел «Расширение»).
2. **Гейтинг только на сервере.** Каждый API/Server Action, отдающий контент, проверяет тариф через `assertAccess()`. UI лишь отражает решение сервера. Закрытый контент (видео-id, промпты, файлы) не должен попадать в ответ для пользователя без доступа.
3. **Единый контент-юнит.** Уроки, юзкейсы и эфиры рендерятся одним компонентом `<ContentUnit />` и редактируются одной админ-формой. Не дублируй.
4. **Фаза 2 не строится**, но схема и слои не должны ей мешать (см. `00-overview.md`, «Заделы под Ф2»).
5. **152-ФЗ.** Данные хранятся в РФ-контуре, есть согласие на обработку ПДн, куратор читает только учебные данные (Progress, чек-лист, бизнес-профиль), не переписку.
6. **Ключи студента не храним.** Платформа выдаёт промпты/скиллы, но не хранит API-ключи Claude/Telegram студента.
7. **Язык.** UI и контент на русском. Код, идентификаторы, коммиты на английском.
8. Мелкие коммиты (Conventional Commits), после каждого завершённого экрана или API-группы. Тесты для гейтинга и оплаты обязательны.

## Команды (после Этапа 1 должны работать)

```bash
pnpm install
pnpm db:up          # docker compose up -d postgres
pnpm db:migrate     # prisma migrate dev
pnpm db:seed        # тарифы, роли, демо-контент, admin
pnpm dev            # http://localhost:3000
pnpm lint && pnpm typecheck && pnpm test
pnpm test:e2e       # playwright
```

## Definition of Done для любой задачи

- Типы, линт и тесты зелёные.
- UI сверен с эталоном стиля, проверен на 375 px и 1440 px.
- Гейтинг проверен тестом (доступ и отказ).
- Нет захардкоженных секретов, всё через `.env` (см. `.env.example`).
