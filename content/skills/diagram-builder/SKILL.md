# Схема процесса или системы

## Когда использовать

Применяй для flowchart, sequence, mind map или архитектурной схемы. Формат файла выбирай по доступному инструменту; навык не привязан к Miro или Excalidraw.

## Порядок работы

1. Определи аудиторию и вопрос, на который должна ответить схема.
2. Выбери тип: поток для решений, sequence для взаимодействий, карта для иерархии, архитектура для компонентов.
3. Ограничь верхний уровень 5–9 узлами; детали вынеси на отдельную схему.
4. Используй одно направление чтения и единые формы для одинаковых сущностей.
5. Подпиши условия на стрелках, границы систем и владельцев.
6. Сверь схему с текстовым источником и проверь каждый переход.

## Проверка

У схемы есть начало/контекст, легенда при необходимости и ясный основной путь; неизвестные связи помечены, а не выдуманы.
