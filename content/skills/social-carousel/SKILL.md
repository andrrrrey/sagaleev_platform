# Сценарий социальной карусели

## Когда использовать

Применяй для многостраничного визуального поста. Этот навык создаёт содержание и ТЗ; рендеринг выполняет отдельный дизайн-инструмент.

## Порядок работы

1. Определи аудиторию, платформу, цель, один тезис и доказательство.
2. Сделай обложку с конкретным обещанием ценности без кликбейта.
3. Построй последовательность: проблема → объяснение → пример → действие.
4. Один слайд — одна мысль; вынеси детали в подпись.
5. Для каждого слайда опиши текст, визуальную роль и источник факта.
6. Последний слайд завершает мысль и предлагает один CTA.

## Проверка

Карусель понятна без подписи; порядок нельзя переставить без потери логики; текст помещается в выбранный формат; утверждения проверены.
