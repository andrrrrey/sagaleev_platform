# Коммерческое предложение

## Когда использовать

Применяй после квалификации клиента, когда известны задача, объём, ограничения и модель цены. Не придумывай кейсы, гарантии и экономический эффект.

## Порядок работы

1. Сведи контекст клиента и проверь, что проблема сформулирована его словами.
2. Уточни результат, границы работ, исключения, этапы и критерии приёмки.
3. Рассчитай стоимость только по утверждённому прайсу или входным данным.
4. Все переменные и допущения вынеси отдельно.
5. Сформулируй риски и обязанности обеих сторон.
6. Добавь один ясный следующий шаг без искусственного давления.

## Структура

Контекст → предлагаемое решение → состав работ → результат → сроки → стоимость → что не входит → условия клиента → риски → приёмка → следующий шаг.

## Проверка

Цена пересчитана; сроки не противоречат этапам; обещания имеют критерий; конфиденциальные сведения другого клиента отсутствуют.
