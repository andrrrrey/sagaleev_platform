# Мониторинг темы

## Когда использовать

Применяй для регулярного наблюдения за конкурентами, рынком, регулированием или технологией. Не создавай автоматическое расписание и уведомления без явного поручения.

## Настройка монитора

Зафиксируй тему, решение получателя, географию, язык, источники, частоту, окно сравнения и критерии важности. Отдельно укажи исключения и допустимый уровень шума.

## Каждый запуск

1. Собери изменения после предыдущей контрольной точки.
2. Удали дубли и перепечатки одного события.
3. Проверь дату события, а не только публикации.
4. Оцени важность по влиянию, новизне, достоверности и срочности.
5. Отправляй немедленный алерт только при превышении согласованного порога; остальное включай в дайджест.

## Результат

Событие; почему важно; кого затрагивает; подтверждающие источники; уверенность; рекомендуемое действие; что изменилось с прошлого отчёта.

## Проверка

Алерт содержит новое событие, а не старую статью; вывод прослеживается до источников; расписание не дублируется.
