# Безопасное обновление CRM

## Когда использовать

Применяй для подготовки или выполнения согласованного изменения CRM. Без явного разрешения показывай план/черновик и не записывай данные.

## Порядок работы

1. Найди запись по стабильному идентификатору, а не только по имени.
2. Прочитай текущие значения и версию/время изменения.
3. Покажи diff: поле, было, станет, источник нового значения.
4. Проверь обязательные поля, формат, дубликаты и права.
5. Получи подтверждение на запись, если оно не дано в текущей задаче.
6. После записи перечитай объект и сохрани идентификатор операции.

## Запреты

- Не выполнять массовое обновление без отдельного списка и лимита.
- Не удалять записи и историю.
- Не перезаписывать более новые изменения другого пользователя.
- Не писать секреты и чувствительные заметки в общие поля.

## Проверка

Фактическое состояние совпадает с подтверждённым diff; результат можно откатить или восстановить по журналу.
