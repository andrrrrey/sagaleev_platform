# Анализ пути клиента

## Когда использовать

Применяй для пути от первого контакта до повторного обращения. В чувствительных нишах агрегируй данные и не раскрывай сведения конкретных людей.

## Порядок работы

1. Определи сегмент, начало/конец пути и бизнес-результат.
2. Построй реальные этапы из событий разных систем, сохранив источник каждого события.
3. Для каждого этапа посчитай объём, время, переход и отвал.
4. Добавь ожидание клиента, ответственного, канал и типичную причину потери.
5. Раздели подтверждённые причины и гипотезы.
6. Приоритизируй улучшения по влиянию, риску и сложности измерения.

## Проверка

Один клиент не посчитан несколько раз без правила; периоды сопоставимы; чувствительные данные заменены агрегатами.
