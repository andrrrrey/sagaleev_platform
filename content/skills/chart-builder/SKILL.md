# Деловой график

## Когда использовать

Применяй, когда данные нужно показать визуально. Этот навык проектирует график; публикация через конкретный сервис требует отдельной интеграции.

## Порядок работы

1. Определи вопрос, который график должен разрешить.
2. Проверь данные: единицы, пропуски, период, источник и метод расчёта.
3. Выбери форму: линия для времени, столбцы для сравнения, scatter для связи, таблица для точных значений.
4. Не обрезай ось и не используй двойную ось без явного обоснования.
5. Добавь заголовок-вывод, подписи, источник и примечание к методике.
6. Экспортируй только после визуальной проверки значений и читаемости.

## Проверка

График отвечает на один вопрос; визуальная пропорция соответствует данным; цвета различимы; источник и период указаны.
